# AI Chat Anônimo

Sistema de comunicação anônima desenvolvido com foco em privacidade, segurança e controle de acesso.

## Sobre o projeto

O AI Chat Anônimo é uma plataforma de mensagens criada para oferecer um ambiente de comunicação privado, organizado e seguro.

O sistema permite que usuários utilizem a plataforma mantendo sua identidade protegida, enquanto o administrador possui controle sobre quem pode acessar o ambiente.

O acesso funciona através de um sistema de autorização manual, onde cada novo usuário precisa ser aprovado pelo administrador antes de conseguir utilizar todas as funcionalidades da plataforma.

Essa abordagem permite maior controle dos usuários cadastrados e ajuda a manter um ambiente mais organizado e protegido.

## Funcionalidades

- Cadastro de usuários
- Sistema de autorização manual
- Controle de acesso administrativo
- Comunicação anônima entre usuários
- Interface responsiva
- Gerenciamento de usuários
- Estrutura preparada para expansão
